=== Profile activation ===

$                      ./mvnw help:active-profiles -pl .
    -> local 
$ CI=false             ./mvnw help:active-profiles -pl .
    -> local 
$ CI=true              ./mvnw help:active-profiles -pl .
    -> ci 
$                      ./mvnw help:active-profiles -pl . -Pci
    -> local ci 

# local activates on env.CI != true, which includes CI being unset.
# It deliberately does not use activeByDefault: Maven switches that off as
# soon as any other profile in the same POM activates, so the default
# profile would vanish exactly when a second profile appears.
# Explicit -Pci therefore leaves local active too. Harmless while local is
# empty, and honest: -P adds a profile, it does not replace the default.

Boot 4 serializes with Jackson 3 (tools.jackson); springdoc's swagger-core
still uses Jackson 2 (com.fasterxml.jackson) internally. Different group ids,
different packages: they coexist, and the Boot BOM pins both lines, which is
why convergence passes. Only Jackson 3 touches the ledger's own JSON.

The nearest-wins trap, measured before removing the old declarations.
bootstrap declared org.springframework:spring-web at test scope for stage 4's
request-scope demo. With that declaration still present:
  com.jerome.slledger:bootstrap:jar:0.1.0-SNAPSHOT
